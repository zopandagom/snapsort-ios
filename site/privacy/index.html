간직함 개인정보 처리방침

시행일: 2026년 11월 2일

간직함은 사진을 기기 밖으로 보내지 않고, 사진에서 읽은 글자는 이용자가 눌러 지도 앱으로 넘기는 주소 말고는 기기 밖으로 보내지 않습니다. 개발자는 서버를 운영하지 않으며, 이용자가 기기 설정에서 공유를 켠 경우 Apple 이 익명으로 집계해 주는 통계(6항) 말고는 이용자의 어떤 정보도 받거나 보관하지 않습니다. 계정, 광고, 분석 도구, 추적이 없습니다.

1. 기기 안에서만 처리하는 정보

간직함(이하 "앱")은 이용자가 허용한 사진 보관함의 이미지를 기기 안에서 분석해 기프티콘·영수증·캡처·여행 같은 카테고리로 분류합니다.

  • 사진과 사진 속 글자: 이미지 분류, 글자 인식(OCR), 바코드 인식, 비슷한 사진 찾기는 모두 기기 안의 Apple 프레임워크로 처리합니다. 분류를 돕는 언어 모델도 기기 안에서만 동작하는 Apple 온디바이스 모델만 쓰며, 사진이나 읽은 글자를 외부 서버(Apple 의 Private Cloud Compute 포함)로 보내지 않습니다.
  • 분류 결과: 카테고리, 읽은 글자, 기프티콘 만료일·교환처, 영수증 가게·금액 같은 분류 결과는 앱 전용 저장 공간에만 저장합니다.
  • 알림: 알림 권한은 이용자가 보관함 화면에서 "만료 알림 받기"를 누를 때 요청합니다. 기프티콘 만료 알림은 기기 안에서 예약하는 알림이며, 알림을 위해 정보를 외부로 보내지 않습니다.
  • 위젯: 홈·잠금 화면 위젯에는 개수와 남은 날짜(D-day) 같은 정보만 보이고, 사진이나 읽은 글자는 보이지 않습니다.

2. 기기 밖으로 나가는 정보 (Apple 시스템 서비스)

아래 경우에만 정보가 Apple 의 시스템 서비스로 전달됩니다. 사진은 어떤 경우에도 포함되지 않으며, 사진에서 읽은 글자는 이용자가 눌렀을 때 지도 앱으로 넘기는 주소(아래 세 번째 항목)뿐입니다.

  • 여행 장소 이름 찾기: 여행 폴더에 장소 이름을 붙이기 위해, 사진에 기록된 위치를 약 1km 단위로 반올림한 대략적인 좌표와 장소 이름을 받을 언어(기기의 언어·지역 설정)만 Apple 지도 서비스(MapKit)로 보내 장소 이름을 받아 옵니다. 사진마다가 아니라 여행 장소마다 보냅니다. 앱이 화면 뒤에 있거나 닫혀 있을 때 시스템이 실행하는 백그라운드 분류 중에도 같은 반올림 좌표와 언어만 보냅니다. 받은 장소 이름은 기기 안에만 저장합니다.
  • 여행 지도 표시: 여행 폴더 상세 화면을 열면 지도를 그리기 위해 Apple 지도 서비스에 지도 이미지를 요청합니다. 처음에는 반올림한 여행 중심점 주변 영역을 요청하고, 이용자가 지도를 끌거나 확대하면 그 영역의 지도 이미지를 요청합니다. 이는 지도 앱으로 지도를 둘러볼 때와 같습니다.
  • 지도 앱으로 주소 넘기기: 캡처 이미지에서 읽은 주소는 이용자가 직접 눌렀을 때만 Apple 지도 앱으로 넘깁니다. 앱이 자동으로 주소를 보내거나 주소의 위치를 찾지 않습니다.

위 요청은 Apple 이 처리하며 Apple 개인정보 처리방침을 따릅니다. 앱은 위치 권한을 요청하지 않으며, 좌표는 이용자가 허용한 사진에 기록된 위치 정보에서 읽습니다.

3. 복사

송장·계좌번호 같은 번호를 복사하면 이 기기에서만 붙여 넣을 수 있게 복사합니다. 같은 Apple 계정의 다른 기기로 넘어가는 공통 클립보드(Universal Clipboard)로는 전달되지 않습니다. 앱은 클립보드를 읽지 않습니다.

4. 백업과 동기화

분류 결과 저장 파일은 iCloud 백업과 컴퓨터 백업에서 제외되며, iCloud 동기화도 하지 않습니다. 따라서 읽은 글자를 포함한 분류 결과가 백업을 통해 기기 밖으로 나가지 않습니다. 기기를 바꾸거나 백업에서 복원하면 앱이 사진 보관함을 처음부터 다시 분류합니다.

5. 사진 접근과 삭제

  • 사진 보관함 접근 권한은 이용자가 첫 화면에서 "정리 시작하기"를 누를 때 요청하며, 일부 사진만 허용하면 허용한 사진만 분류합니다. 권한은 언제든 설정 앱에서 바꿀 수 있습니다.
  • 정리 도우미에서 사진을 지우는 것은 이용자가 직접 고르고 시스템 확인 창에서 허락했을 때만 이루어집니다.

6. 수집하지 않는 정보

앱에는 회원 가입·로그인이 없고, 개발자의 서버가 없습니다. 광고, 광고 식별자(IDFA), 분석·크래시 보고 도구 같은 외부 SDK 를 쓰지 않으며, 이용자를 추적하지 않습니다. 개발자가 받는 정보는 이용자가 기기 설정에서 "앱 개발자와 공유"를 켠 경우 Apple 이 집계해 제공하는 익명 통계·충돌 보고뿐입니다.

7. 보관 기간과 삭제

분류 결과는 기기 안에만 있으며, 앱을 삭제하면 함께 삭제됩니다. 개발자는 이용자 정보를 보관하지 않으므로 별도로 열람·삭제를 요청할 정보가 없습니다.

8. 아동의 개인정보

앱은 연령과 관계없이 어떤 개인정보도 수집하지 않습니다.

9. 처리방침 변경

처리방침을 바꾸면 이 페이지에 시행일과 함께 게시합니다. 지난 내용은 변경 기록에서 볼 수 있습니다.

10. 이 페이지

이 처리방침 페이지는 GitHub Pages 로 게시됩니다. 앱이나 웹 브라우저에서 이 페이지를 열면 브라우저가 GitHub 에 접속하며, 접속 정보(IP 주소 등)는 GitHub 개인정보 처리방침에 따라 GitHub 이 처리합니다. 앱은 이 페이지를 열 때 아무 정보도 보내지 않으며, 개발자는 접속 기록을 받지 않습니다.
